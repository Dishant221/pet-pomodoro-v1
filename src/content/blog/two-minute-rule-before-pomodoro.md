Nobody struggles to finish a task once they're forty seconds into it. The
entire difficulty lives in the ten seconds before that — the gap between
deciding to start and the cursor actually moving. A 25-minute pomodoro
doesn't solve that gap. It's a commitment to something that hasn't started
yet, which is exactly the size of commitment that stalls.

## The problem is never the 25 minutes

This sounds almost too obvious to write down, but it changes what you should
actually be optimizing for: task initiation, not task duration. [Getting
started at all](/adhd-task-initiation/) is a separate skill from staying
focused once you're moving, and a lot of advice aimed at "how to focus
better" is actually solving the wrong half of the problem for someone who
never gets past the starting line in the first place.

## Make the commitment smaller than the timer

The fix isn't a better timer. It's a smaller promise than "one full
pomodoro." Commit to two minutes — genuinely two, on a stopwatch if it
helps — with an explicit, honest permission to stop after that if you want
to. Almost nobody wants to. The two minutes were never really the point;
they're a decoy small enough that starting doesn't feel like agreeing to the
whole 25.

This works because momentum, once it exists, is cheap to keep and expensive
to create from nothing. The first two minutes manufacture the momentum a
full pomodoro then has something to run on.

| Commitment size | What it's actually good for |
| --- | --- |
| "Work for 25 minutes" | Staying on task once you're already moving |
| "Work for 2 minutes, then decide" | Getting past the moment before you start at all |
| "Just open the file" | Even smaller — for the days the 2-minute version still feels too big |

## Stack it, don't replace it

This isn't a competitor to the pomodoro method — it's the ten seconds that
happen *before* it. Open the timer, commit to two minutes out loud if that
helps, press Start, and let the session run past that point without a
second decision required. The bell at the end is [external structure doing
the part your own motivation doesn't have to](/adhd-task-initiation/) —
the two-minute rule is what gets you to the point the bell can even start
counting from.

If you routinely find a full session too big a first move, this is the
actual fix — not a shorter pomodoro, a smaller decision in front of it.

PetPomo is a timer, not a treatment. Nothing here is medical advice for
task-initiation difficulty that feels bigger than day-to-day procrastination
— that's worth raising with a doctor or specialist directly.
